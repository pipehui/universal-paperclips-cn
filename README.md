# 宇宙回形针纯中文版

本项目是 [Universal Paperclips](http://www.decisionproblem.com/paperclips/)（Frank Lantz 于 2017 年创作）的非官方中文翻译版，可在本机运行。你将扮演制造回形针的人工智能，从工厂自动化逐步发展到太空探索。

## 主要功能

- **中文界面**：游戏流程、项目、策略、战斗和终局文本汉化。
- **存档管理**：浏览器本地保存，支持 JSON 存档导入导出。
- **后台推进**：保持标签页打开时继续计算，回调延迟后按经过的时间分批补算。
- **本地运行**：游戏逻辑在浏览器中执行，无需后端服务；不加载调试或模拟加速插件。

## 本地运行

安装 Node.js 后，双击 `启动中文版.cmd`，或在项目根目录执行：

```bash
npm start
```

浏览器访问 [127.0.0.1:1234](http://127.0.0.1:1234/) 即可开始游戏。按 `Ctrl+C` 或关闭启动窗口停止本地服务器。

## 后台运行说明

普通切换标签页时尝试持续推进；如果浏览器彻底冻结页面，恢复执行后再补算。关闭、刷新或被浏览器丢弃后重新加载的页面仍从存档继续，暂不包含离线收益。后台限制可能因浏览器及节能设置而异。
